## Short description (150 words max)

AI coding agents write long plans and replies, then stop and wait for a person. Today's glasses tools let you approve, or say one sentence. That is not feedback. Pinpoint is for developers who run agents such as Claude Code and Codex through T3 Code and step away from the laptop.

Pinpoint splits each agent reply into 4–10 one-line points, each tied to an exact quote from the source. On Even G2 you swipe to a point, stay silent to agree, or tap and speak one correction. One tap sends a review that cites every point it changes. Telegram carries the same thread as a topic, with the full text, quote-replies on exact sentences, and an alert while the glasses app is closed.

Tracks: AI Assistants & Work (main), Messaging & News (second), plus the Best Telegram integration special prize.

## Long description (400 words max)

**The problem.** AI coding agents produce replies of several hundred words, then stop and wait for a human. On a laptop you answer by selecting a sentence and writing a correction. On glasses you can approve a prompt or dictate one sentence. Neither says which step is wrong, or why.

**Who it is for.** Developers who run coding agents such as Claude Code and Codex through T3 Code, and are away from the keyboard when one stops.

**How it works.** Pinpoint reads the T3 Code threads that need a person: a plan, a question, a failed run, or a report. The server splits it into 4–10 one-line points. Every point carries an exact quote from the source; a point whose quote cannot be found is repaired from the source or dropped, so the glasses never show invented text.

On the G2, the list is four rows at a time. Swipe to move the focus. Silence means agree. Tap, speak one sentence, tap again: the point becomes an objection or a note. An agent question becomes a short list of options, one tap each. When you reach the end, one tap composes a review that cites each changed point by number and quote, shows a two-line preview, and sends it as a normal user message. The agent reads it as feedback and continues.

**Why glasses.** The moment is hands-free. Ten lines on a 576 × 288 display force the agent's long reply down to the decisions that matter, and the review is shorter and more precise than most laptop typing.

**Telegram.** Each thread also gets a topic in a private Telegram group: a header with an agree-all button, the full formatted reply, and your review. Each objection or note appears as a quote-reply on the exact sentence. "Read on phone" opens that point from a deep link. Telegram also covers the platform gap: a bot message becomes a phone notification that the glasses mirror, so you hear about a waiting plan even when the app is closed.

**Safety.** Keys stay on the local server. Live mode reads only the T3 projects on an explicit allowlist. Nothing is sent until you confirm the preview, and Pinpoint never approves shell commands or permission prompts. The demo runs offline with fixed fixtures.

Tracks: AI Assistants & Work (main), Messaging & News (second), plus the Best Telegram integration special prize.
